# bikemap

Interactive bike network map for Toronto and Edmonton. Each route is styled by how separated it is from cars: protected lanes and bike paths, multi-use trails, buffered and painted lanes, and sharrows. You can switch to a comfort-level view (high, medium, low) inspired by the Can-BICS classification, and customize the colour, thickness and dash pattern of every category.

Data loads live from [OpenStreetMap](https://www.openstreetmap.org/copyright) through the Overpass API. Basemap tiles © Esri and OpenStreetMap contributors.
